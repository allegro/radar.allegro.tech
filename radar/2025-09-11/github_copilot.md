GitHub Copilot is an AI-powered set of tools helping with the entire Software
Development Lifecycle. Most of them are visible in IDE (chat, code suggestions,
Next Edit Suggestions), but increasingly they are being integrated into other
places as Github Web (asynchronous agentic mode and code review, web chat,
github actions) and even Mobile.
