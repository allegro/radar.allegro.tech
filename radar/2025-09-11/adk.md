The Agent Development Kit (ADK) is an open-source, code-first Python framework designed to simplify
the development, orchestration, and deployment of agentic systems. ADK provides high-level
abstractions for core concepts such as agents, their memory, and workflows. It allows the orchestration
of agent workflows using sequential, parallel, or looping execution patterns, enabling the creation of
modular systems.
